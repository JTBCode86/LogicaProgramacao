# 🎮 Jogo do Número Secreto

Este é um projeto desenvolvido durante o curso de **Lógica de Programação com JavaScript** da **Alura**. Trata-se de um jogo interativo onde o usuário tenta adivinhar um número secreto gerado aleatoriamente pelo computador.

---

## 🚀 Funcionalidades do Jogo

- **Geração Aleatória:** O computador escolhe um número secreto de forma aleatória (neste projeto, configurado até o valor máximo de $5000$).
- **Interatividade:** O usuário recebe dicas em tempo real através de caixas de diálogo (`prompt` e `alert`), indicando se o número secreto é **maior** ou **menor** que o palpite dado.
- **Contador de Tentativas:** O jogo registra a quantidade de tentativas necessárias até que o jogador acerte o número secreto.
- **Estruturas de Repetição e Condicionais:** O código utiliza laços de repetição (`while`) e condicionais (`if`, `else`) para controlar o fluxo da partida.

---

## 🛠️ Tecnologias Utilizadas

- **JavaScript:** Para a lógica do programa, manipulação de variáveis, operadores e funções matemáticas (`Math.random`).
- **HTML5 e CSS3:** Para a estrutura e estilização da página do jogo.

---

## 📂 Como Executar o Projeto

1. Baixe ou clone este repositório em sua máquina.
2. Certifique-se de manter a estrutura de pastas correta (com os arquivos `index.html`, `app.js`, `style.css` e a pasta de imagens).
3. Abra o arquivo **`index.html`** em qualquer navegador web de sua preferência para começar a jogar!
